# 단체여행자보험 가입 사이트 개발 문서

## 프로젝트 개요

단체여행자보험 가입을 위한 웹사이트를 개발했습니다. 사용자가 단체 여행 보험에 가입할 수 있도록 정보를 입력하고 신청할 수 있는 인터페이스를 제공합니다.

## 개발 일자

2025년 12월 11일

## 개발 환경

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- 반응형 웹 디자인

## 주요 기능

### 1. 보험 정보 안내
- 보장 내용 섹션 제공
- 주요 보장 항목:
  - 여행 중 상해 및 질병으로 인한 의료비 보장
  - 항공기 지연 및 여행 취소 보상
  - 수하물 분실 및 손상 보상
  - 긴급 귀국 비용 지원
  - 24시간 긴급 지원 서비스

### 2. 가입 신청 폼
다음 정보를 입력받습니다:

#### 필수 입력 항목
- **단체명 / 회사명**: 보험 가입 단체의 이름
- **담당자 성명**: 보험 가입 담당자 이름
- **연락처**: 담당자 전화번호
- **이메일**: 담당자 이메일 주소
- **여행자 수**: 최소 2명 이상 (단체 보험 특성)
- **여행지**: 여행 목적지
- **출발일**: 여행 출발 날짜
- **귀국일**: 여행 귀국 날짜
- **보험 종류**: 
  - 기본형 (의료비 5천만원)
  - 표준형 (의료비 1억원)
  - 프리미엄형 (의료비 2억원)

#### 선택 입력 항목
- **추가 요청사항**: 특별 요청사항이나 문의사항

### 3. 유효성 검사
JavaScript를 통한 클라이언트 사이드 유효성 검사:
- 출발일은 오늘 이후 날짜만 선택 가능
- 귀국일은 출발일 이후 날짜만 선택 가능
- 여행자 수는 최소 2명 이상
- 필수 항목 입력 확인
- 날짜 논리 검증 (귀국일 > 출발일)

## 디자인 특징

- 메인 그라데이션: 보라색 계열 (#667eea → #764ba2)

- 모바일 친화적 디자인 (768px 이하에서 1열 레이아웃)

### UI/UX 요소
- 부드러운 전환 효과 (transition)
- 포커스 상태 시각적 피드백
- 호버 효과 (버튼)
- 필수 항목 표시 (빨간색 별표)

## 기술적 세부사항

### HTML 구조
- 시맨틱 HTML5 태그 사용
- 접근성을 고려한 레이블 및 입력 필드 연결
- 한국어 언어 설정 (`lang="ko"`)

### CSS 스타일링
- 모바일 퍼스트 접근 방식
- CSS Grid를 활용한 반응형 레이아웃
- 커스텀 CSS 변수 없이 직접 색상 값 사용
- Flexbox 및 Grid 혼합 사용

### JavaScript 기능
- 날짜 입력 필드 동적 제한
- 폼 제출 이벤트 처리
- 클라이언트 사이드 유효성 검사
- 사용자 피드백 (alert)

## 향후 개선 사항

1. **백엔드 연동**
   - 실제 서버로 데이터 전송 기능
   - 데이터베이스 저장

2. **사용자 경험 개선**
   - alert 대신 모달 창 사용
   - 로딩 상태 표시
   - 성공/실패 메시지 개선

3. **추가 기능**
   - 보험료 계산기
   - 보험 약관 동의 체크박스
   - 파일 업로드 (여행자 명단 등)
   - 이메일 인증

4. **보안 강화**
   - CSRF 토큰
   - 입력 데이터 검증 강화
   - HTTPS 적용

5. **접근성 개선**
   - ARIA 레이블 추가
   - 키보드 네비게이션 개선
   - 스크린 리더 지원

## 사용 방법

1. `index.html` 파일을 웹 브라우저에서 엽니다
2. 보장 내용을 확인합니다
3. 가입 정보를 입력합니다
4. "가입 신청하기" 버튼을 클릭합니다
5. 유효성 검사를 통과하면 신청 완료 메시지가 표시됩니다

## 참고사항

- 현재는 프론트엔드만 구현되어 있으며, 실제 데이터 저장 기능은 없습니다
- 폼 제출 시 alert로 완료 메시지만 표시됩니다
- 실제 운영 환경에서는 백엔드 서버와 연동이 필요합니다
